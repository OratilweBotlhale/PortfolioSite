ORATILWE RADIKELEDI PORTFOLIO WEBSITE

FILES
- index.html: Website structure and content
- styles.css: Complete responsive styling and animations
- script.js: Mobile navigation and scroll-reveal interactions
- Oratilwe_CV.pdf: Downloadable CV used by the website

HOW TO USE
1. Extract the ZIP file.
2. Keep all four files in the same folder.
3. Open index.html in a browser to view the site locally.
4. Upload all files to the public_html or website root folder on your hosting account.

The website is static and does not require WordPress, a database, Node.js or a build process.

External services used:
- Google Fonts (Inter and Space Grotesk)
- Links to live project websites, GitHub and LinkedIn

## Running The Website Locally

This is a static website and does not require Node.js, a package manager, a database or a build process.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, clone the repository with Git:

```bash
git clone https://github.com/OratilweBotlhale/PortfolioSite.git
cd PortfolioSite
```

Then open `index.html` in your preferred browser.

## Deploying With GitHub Pages

1. Upload the project files to the repository's `main` branch.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder.
6. Save the settings and wait for GitHub Pages to publish the website.

The `index.html` file must remain in the repository root for this setup.

## Updating The Portfolio

- Edit page content in `index.html`.
- Update colours, spacing and responsive styling in `styles.css`.
- Update navigation and scroll animations in `script.js`.
- Replace `Oratilwe_CV.pdf` with a newer CV while keeping the same filename, or update the CV links in `index.html`.
